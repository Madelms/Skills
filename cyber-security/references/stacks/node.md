# Node.js Stack Hints

Inspect Express/Fastify/Nest middleware order, route guards, JWT verification, cookie/session configuration, body parsers, file handlers, ORM query construction, `child_process`, filesystem APIs, CORS and error middleware.

Look for `jwt.verify`, route middleware arrays, `req.user`, `req.params`, `req.body`, `fs`, `path.join`, `exec`, `spawn`, raw SQL and permissive CORS.
